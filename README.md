# AI小説スタジオ

ブラウザだけで動く、AIと一緒に小説を書くためのエディタです。インストール不要で、PCでもスマホでも使えます。

## 使い方

1. `novel-studio.html` を開く（GitHub Pages で公開している場合はそのURLを開く）
2. 右下の「AI接続設定」で、使うAIを選ぶ
   - OpenRouter（無料モデルあり・要APIキー）
   - Claude API（有料・要APIキー）
   - Ollama / LM Studio（PCのローカルLLM）
3. 下の入力欄から、AIに続きを書かせたり（執筆モード）、直前の文章を書き直させたり（推敲モード）できます

スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使えます。

## データの保存場所

書いた原稿・設定・APIキーは、開いたブラウザの中（IndexedDB）にだけ保存されます。このリポジトリやサーバーには送られません。
端末を変えるときやバックアップには「書き出し」「読み込み」を使ってください。

## ファイル

- `novel-studio.html` … アプリ本体（1ファイル）
- `index.html` … 公開URLの入口
- `manifest.webmanifest`, `icons/` … ホーム画面に追加したときのアイコン
- `build-artifact.ps1` … claude.ai のアーティファクト版を作るスクリプト
