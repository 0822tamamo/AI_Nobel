追加する項目を選んでください。内容は追加したあとでも編集できます。

PCとスマホの同期（GitHub）

原稿を、あなたのGitHubの非公開リポジトリに保存して、どの端末からも同じ内容を開けるようにします。使う端末ごとに一度だけ設定してください。
はじめての設定手順
  1. GitHubで新しいリポジトリを作ります。名前は例えば AI_Nobel_data。Private を選び、「Add a README file」にチェックします。
  2. トークンの作成ページを開きます。Repository access で「Only select repositories」を選び、作ったリポジトリだけを指定します。
  3. Permissions →「Repository permissions」の Contents を「Read and write」にして作成します。
  4. 表示されたトークン（github_pat_ で始まる文字列）をコピーして、下に貼り付けます。
トークンはこの端末のブラウザ内にだけ保存されます。
